# BTL-14-LineWatch

## 1. Giới thiệu
LineWatch là dự án phát triển giao diện web hỗ trợ theo dõi dây chuyền sản xuất và báo cáo sự cố trong quá trình vận hành.

Dự án được thực hiện trong học phần CSE122 – Phát triển ứng dụng Web cơ bản.

## 2. Màn hình thực hiện
**LW-03 – Báo sự cố (Incident Create)**

Màn hình cho phép người dùng:
- Chọn dây chuyền và máy xảy ra sự cố.
- Nhập thời điểm và mô tả hiện tượng.
- Chọn mức độ ảnh hưởng ban đầu.
- Chọn ảnh đính kèm.
- Lưu nháp và thực hiện thao tác gửi báo cáo.
- Xem và thao tác với bảng gợi ý phân loại sự cố AI.

## 3. Công nghệ sử dụng
- **HTML5:** Xây dựng cấu trúc giao diện.
- **CSS3:** Thiết kế giao diện, bố cục và Responsive.
- **JavaScript:** Xử lý tương tác, kiểm tra dữ liệu và lưu nháp trên trình duyệt.

## 4. Cấu trúc dự án
- `index.html`: Cấu trúc trang Báo sự cố.
- `css/style.css`: Định dạng giao diện và Responsive.
- `js/main.js`: Xử lý các chức năng tương tác.
  
## 5. Cách chạy dự án
1. Tải hoặc clone mã nguồn về máy.
2. Mở thư mục dự án bằng Visual Studio Code.
3. Chạy file `index.html` bằng Live Server.
